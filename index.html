Windows System Telemetry, Mastered.

Project Guru is a lightweight, independent C++ agent that watches over your Windows endpoints — health, restore points, and process activity — without the bloat of a full monitoring suite.

Built for signal, not noise

Three focused capabilities that keep endpoints observable without the overhead.

System Health Tracking

Continuous visibility into CPU, memory, disk, and service state so drift and degradation are caught before they become incidents.

Restore Point Management

Tracks system restore point creation and coverage, flagging endpoints that are left without a recent recovery snapshot.

Process Metrics

Captures running process and installed-program inventories, surfacing changes that matter for security and compliance review.

Why Project Guru exists

Built out of a real problem, not a product roadmap.

A lot of us end up as the unofficial IT department for family and friends. For me, that included my mother, a 5.5-hour drive away. The problem was never the easy stuff — nobody calls when something small goes wrong. They call when the computer won't turn on, or the screen stays black, and by then the problem has usually been quietly getting worse for weeks.

What was actually needed was a way to see into the machine remotely: what software is installed, what changed recently, whether backups and restore points exist, whether the antivirus and firewall are actually on, whether the disk is throwing errors before it fails outright. Not control — insight, and an early warning before a small problem becomes a disaster call.

Core principle

An observer, not a remediator

Project Guru will never turn the firewall back on, update the antivirus, or fix anything for you — doing that automatically on someone else's machine is a good way to cause a different disaster. As the automated analysis grows, this stays the line it won't cross.

  • Reports what's installed, changed, or failing, and flags developing problems early.
  • Gives you the history to diagnose it ("it was working last week") before you remote in.
  • Never changes settings, fixes issues, or takes remote control on its own.

Simple, secure architecture

The Project Guru agent is a standalone C++ client that runs directly on the endpoint. It collects telemetry locally and securely communicates with a custom backend service using Protocol Buffers over HTTPS — a compact, strongly-typed wire format that keeps both the agent and server lightweight and independent of any third-party monitoring platform.
